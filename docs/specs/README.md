## 文件規則

- 所有文件和參考資料都放在 `docs/` 底下：
  - `docs/specs/`：規格文件，一個主題一份，不另外保留舊版計畫或實測紀錄；重要的實測結論直接寫進對應的規格。
  - `docs/art-image/`：風格參考圖。這些是其他畫家的作品，只在本機使用，已被 git 忽略；所以有些編輯器會把它顯示成灰色或隱藏，但檔案還在。
- 寫的是**現在的狀態**。功能狀態一律標「已做」「部分做到」或「未做」。
- 改了程式就同步更新文件；有差異時以程式為準。
- 低優先的待修問題集中在 [vocab-quiz.md](vocab-quiz.md) 的「待改進」。

## 已確定的使用者偏好

這些是使用者試過幾個版本後選定的，修改前要先確認：

- **操作要簡單**：對話一句一個框，「慢速」按鈕就在那句旁邊；所有能按的東西都是有框的按鈕。
- **畫面**：維持傍晚台灣街角的像素街景，以及現在的有限配色。
- **聲音**：正常速度用 Chirp 3 HD，慢速用 Neural2；背景音樂是安靜的水晶鈴聲風格。
