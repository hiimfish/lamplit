## 出題

任務練習（`buildTaskPractice`）依這個順序，由易到難：

1. 每個新單字一題「聽音選圖」。
2. 每組新對比詞兩題「聽辨挑戰」，兩個字各考一次，先後隨機。選項只有這兩個字，不附圖。
3. 每個新詞塊一題「聽音選字」。
4. 任務的 `cloze` 每個項目一題「聽力填空」。
5. 劇情中每句「你」的台詞，若前一句是 NPC 說的，出一題「選回應」。提示文字依那句 NPC 台詞的角色寫「店員說了這句」或「房東說了這句」。
6. 任務的 `signs` 每張招牌一題「讀招牌／價目」。
7. 任務的 `pictures` 每個項目一題「看圖選句」。
8. 任務的 `fills` 每個項目一題「句子填空」。
9. 任務的 `passages` 每篇短文的每個問題一題「讀短文」，同一篇的題目接在一起。
10. 任務的 `talks` 每段對話的每個問題一題「聽對話答題」，同一段的題目接在一起。
    10a. 任務的 `responds` 每個項目一題「應答題」（第四幕，2026-11-23 加）。
11. 每個新詞塊一題「排句子」（只有一個字的詞塊略過）。
12. 任務的 `spellWordIds` 每個字一題「打字拼字」。
13. 每個新詞塊一題「跟我說」。

第 4、6、7 項是 2026-11-22 加的，第一幕就用；第 8～10 項也是 2026-11-22 加的，第二幕才有單元用到（2026-11-23）：閱讀和聽力理解放在排句子之前，由短到長（一句、一篇短文、一段只聽不看的對話）。沒有這些欄位的任務，順序和原本一樣。

搬家第一天每個任務有 2 個單字、2 組對比詞、2 個詞塊，所以一個任務 14 題，比咖啡廳（7～11 題）長。

規則：

- 選項一定打亂，至少 2 個，正確答案只出現一次。
- 干擾選項來自同單元的其他單字或詞塊，以及詞塊自己的 `distractors`（每個都標了錯誤類型）。
- 排句子的字塊一定不會剛好是正確順序。
- 排句子的字塊去掉頭尾標點（「latte,」變成「latte」），避免標點提示位置；字中間的撇號和連字號保留（I'm、take-out）。
- 出題用固定種子的亂數，方便測試重現。
- 角色扮演大挑戰（`buildRolePlayTurns`）：照對話順序，每句「你」的台詞出一題排句子。
  - 字塊來自整句台詞，可以比詞塊多字（例如 Can I get a muffin, please?）。
  - 可接受的答案是台詞本身；台詞和詞塊完全一樣時，再加上詞塊的 `accept`。
  - 用那句的詞塊排複習。
  - 提示寫「換你說：把單字排成你要說的話」。中文不會因為設定的「顯示中文」自動出現，要按「看中文」，算用了幫助，因為這一關的提示是前面的對話。
- 今日複習（`buildReviewQuestions`）以「聽音選圖／選字」和「排句子」為主；到期的對比詞出一題「聽辨挑戰」，隨機考其中一個字。還不會出「打字拼字」「聽力填空」「讀招牌／價目」「看圖選句」「句子填空」「讀短文」「聽對話答題」（2026-11-22 加新題型時沒有改這個函式）。

## 打字拼字

- 出題：`buildTaskPractice(unit, task, rng, units)` 依任務的 `spellWordIds` 每個字出一題（`SpellQuestion`，`kind: 'spell'`）。字可能是更早的單元教的，所以 `TaskScreen` 傳入全部單元（`UNITS`）去找。
- 只考一個純字母的字（`/^[a-z]+$/i`）；像 trash can 這種有空白的字會略過。
- 聲音用教那個字的單元的單字音檔（例如 `move_in.word.key`），不用另外產生音檔。
- 畫面（`src/ui/minigames/Spell.tsx`）：提示「聽聽看，拼出這個字」，加上那個字的像素圖和中文；「再聽一次」「慢速」（慢速算用了幫助）；每個字母一個空格。
- 鍵盤：畫面上的 QWERTY 字母鍵，共三排，最下排最後是 ⌫ 和「檢查」。不叫出系統鍵盤，所以不會自動修正，頁面也不會被擠小。實體鍵盤也能打（字母、Backspace、Enter）；在設定對話框裡打字時不算作答。
- 批改用 `gradeAnswer`，答錯一樣有錯誤類型（例如拼錯）。檢查後每個字母格依位置標出對錯（`spellMarks`）：對的是綠色，錯的是紅色加刪除線；回饋顯示正確拼法。
- 「很快」的門檻和排句子一樣是 12 秒（見 [learning.md](learning.md)）。
- 2026-11-22 用無頭 Chrome 在手機直向 390×844 和橫向 844×390 看過：不用捲動就放得下，console 0 個錯誤，故意答錯也一樣。
- 從便利商店到公園，每個地點的 t7 都有 5 個字，共 40 個字，考的都是前面地點教過、有像素圖的字。

## 聽力填空

狀態：已做（2026-11-22）。從街道 t6 開始，街道到公園每個地點的 t6 各 3 題，共 21 題。第二幕的 8 個地點 t6 也各 3 題，共 24 題（2026-11-23）。

- 出題：`buildTaskPractice` 依任務的 `cloze` 每個項目出一題（`ClozeQuestion`，`kind: 'cloze'`）。內容欄位見 [content.md](content.md)。
- 畫面（`src/ui/minigames/Cloze.tsx`）：提示「聽聽看，空格裡是哪個字？」。自動播放那句台詞（用台詞自己的音檔，是 NPC 的聲音），畫面顯示整句英文，其中一個字換成空格；有「再聽一次」「慢速」（慢速算用了幫助）。下面是 3 或 4 個字的按鍵（答案加上 2 或 3 個錯的字），順序打亂。
- 中文：整句的中文照設定的「顯示中文」出現。
- 大小寫：被挖掉的字在句子裡是大寫開頭時（例如句首的 Old），每個選項都改成大寫開頭，所以大小寫不會洩漏答案。
- 找字：只比對完整的字，不分大小寫（挖 bus 不會切到 business）。找不到那句或那個字時，這一題不出。
- 答完：空格填上正確的字，框變成綠色（不管選對選錯都一樣；選錯的那個按鍵另外標成答錯）；再播一次整句；回饋顯示整句英文。
- 批改：選對就對，選錯記為 `wrong-choice`，提示是「再聽聽看標準說法。」。
- 排程：
  - 挖掉的字和某個教過的單字寫法一樣（不分大小寫）時，算那個單字（`word:<id>`）的一次複習。單字可以是更早的地點教的。
  - 否則，那句台詞有詞塊時，算那個詞塊（`chunk:<id>`）。
  - 都不是時用 `NO_ITEM`：只計入這一輪和當天的答題數，不產生複習卡片。
  - 挖掉的字是教過的單字加 -s 或 -es（minutes、prices、tissues）時，也算那個單字。第一幕 21 題全部算單字。
- 「很快」的門檻是 12 秒，和排句子一樣。

## 讀招牌／價目

- 畫面（`src/ui/minigames/ReadSign.tsx`）：提示「看招牌，回答問題」。上面是一塊深色招牌、淺色字：標題（有的話），下面一行一行，價錢或時間靠右。招牌下面是一個英文問題，中文照「顯示中文」出現。再下面是 2 到 4 個文字答案的按鍵，順序打亂（第一幕都是 3 個）。

### 句子填空

- 對應多益第 5 大題。出題：任務的 `fills` 每個項目一題（`kind: 'fill'`）。沒有聲音。
- 畫面（`Fill.tsx`）：提示「選出最適合放進空格的字」；句子中間是一個有框的空格，下面是 3 或 4 個答案按鍵。空格和最長的那個選項一樣寬，所以填進去時句子不會跳動或重新換行。
- 作答：選的字馬上填進空格，讓學習者看到整句。選對，空格變綠色；選錯，那個錯字留在句子裡加刪除線，正確答案填在它旁邊的空格。畫面上沒有動畫。
- 中文：整句的中文**只在答完後**出現，不管設定的「顯示中文」開或關（先看到中文就等於看到答案）。
- 回饋：選對顯示「答對了！」；選錯顯示「不太對喔」、「你選的「…」放進去不對。」和「正確答案：…」。內容有寫 `note`（一行中文說明為什麼）時，對或錯都顯示。
- 排程：有 `chunkId` 時算那個詞塊（`chunk:<id>`）的一次複習，沒有時是 `NO_ITEM`。第二幕的 17 題裡，哪些有 `chunkId` 由內容決定；內容檢查保證有 `chunkId` 的那題，把答案放進去就剛好是那個詞塊（見 [content.md](content.md)）。

### 讀短文

- 對應多益第 7 大題。出題：任務的 `passages` 每篇的每個問題一題（`kind: 'read-passage'`），每題都帶著整篇短文；同一篇的題目接在一起，有兩題以上時畫面標出「第 1／2 題」。沒有聲音。
- 畫面（`ReadPassage.tsx`）：提示「讀短文，回答問題」。短文放在一張紙條框裡，字的大小和劇情一樣，依種類排成真實的樣子：簡訊是寄件人加一個對話框；email 第一行是「Subject:」加主旨；表格把「項目: 內容」的行排成左右兩欄；傳單、廣告、公告是一個標題加內文。短文沒有中文。
- 手機直向放不下 80 個字加問題和答案時，紙條框讓出高度，在框裡面捲動（至少留約四行）；下面還有字時，框的下緣有一個「▼ 還有」小標籤（不是按鍵），捲到底就消失。橫向時短文在左、問題和答案在右。同一篇的第二、三題會記住紙條框捲到哪裡，不會跳回最上面。
- 問題的中文照「顯示中文」出現；答案是文字按鍵。
- 作答後：短文中答案所在的那一行標出來並自動捲到看得到的地方（找法：第一個把正確答案當成完整的字包含在內的行，不分大小寫；找不到就不標，不亂猜）。選對顯示「答對了！」和正確答案，標得出行時加一句「答案就在短文裡標出來的那一行。」；選錯顯示「看短文裡標出來的那一行。」（沒有標出行時是「再讀一次短文裡寫的。」）和「正確答案：…」。
- 排程：一律 `NO_ITEM`。

### 聽對話答題

- 對應多益第 3 大題。出題：任務的 `talks` 每段的每個問題一題（`kind: 'talk'`），每題都帶著整段對話；同一段的題目接在一起，有兩題以上時提示後面標「（1／2）」。
- 聲音：每句用那句角色的聲線，音檔 id `<單元>.talk.<句子 id>`（`unitToAudioItems` 會列出來）。
- 畫面（`Talk.tsx`）：提示「聽對話，回答問題」，上面有「再聽一次」。一段對話的第一題一開始就自動播，從頭到尾每句接著播：播放時不顯示英文，只顯示兩個說話者的名牌（正在說的那位標 ▶）、一排小點和「第 2／5 句」，下面寫「仔細聽，聽完會出現問題」。播完才出現問題和答案按鍵。同一段的第二、三題直接顯示問題，不再自動播。
- 節奏：開頭停 0.3 秒；換人說話前停 0.5 秒，同一個人接著說停 0.25 秒。某一句如果太久還沒播完（音訊卡住，或瀏覽器語音不回報結束），超過「4 秒加每個字 0.7 秒」就換下一句，不會讓學習者卡在聽的畫面。
- 「再聽一次」重播整段，播的時候停用；答題前按算用了幫助（影響複習評分的規則見 [learning.md](learning.md)，因為這題沒有卡片，目前不影響排程）。
- 問題的中文照「顯示中文」出現。
- 作答後：顯示整段對話的文字，一句一個有框的對話框（顯示中文開著時有中文），每句旁邊有「慢速」；點一句就單獨重聽那一句。選對顯示「答對了！」和正確答案；選錯顯示「看看下面的對話，找出答案在哪一句。」和「正確答案：…」。
- 排程：一律 `NO_ITEM`。
- 對話的角色不用在那個地點的小劇場上（`tests/stageArt.test.ts` 只看劇情台詞的角色）。第二幕有 3 段對話的另一位說話者用 `passerby`（路人）的聲線，一段用「你」（`guide`）。

## 批改

- 比對前先正規化：去掉重音符號（café 當成 cafe，先用 NFD 拆開再過濾）、不分大小寫、去掉標點、把彎引號換成直引號、合併空白。
- 只和「可接受答案」清單比對（詞塊的 `en` 加上 `accept`），不評分自由作答的英文。
- 答錯時判斷錯誤類型：冠詞、單複數、拼錯、順序、少字、多字、其他。每種都有中文提示（`src/learning/errorHints.ts`）。
- 「選回應」答錯時，用該選項標註的錯誤類型給提示。
- 排句子時字都對、只有順序錯，一定判成「順序」，不會因為某個比較短的可接受說法字母比較接近，就判成「多字」。

## 回饋

- 答對顯示「答對了！」，答錯顯示「不太對喔」，並附上提示和正確說法。不只靠顏色表示對錯，也有 ○ / × 標記。
- 作答後一定播放正確的發音。
- 離開題目或介紹卡時（按「繼續」、「開始練習」或「先回小鎮」）停止正在播放的發音。
- 按「繼續」才進下一題，讓回饋停留在畫面上。答題後焦點會自動移到「繼續」，回饋文字會被螢幕閱讀器讀出。
- 按「慢速」會被記為「用了幫助」，影響複習評分（見 [learning.md](learning.md)）。

## 跟我說

- 永遠不會被判錯。
- 「現在不方便說話」可以跳過，記為用了幫助。
- 錄音只留在當次練習的記憶體裡，不會儲存或上傳。
- 錄音期間和等待麥克風權限期間，會停用會衝突的按鈕；離開題目時一定釋放麥克風。
- 錄音格式：依序試 `audio/webm;codecs=opus`、`audio/webm`、`audio/mp4`、`audio/ogg;codecs=opus`，用第一個瀏覽器能錄的格式（Chrome 是 WebM，舊版 Safari 是 MP4）；都不支援時讓瀏覽器自己選。錄音只在同一個瀏覽器播放，所以不需要統一格式。
- 不能錄音時顯示具體原因，結尾都提示可以先跳過這一題：
  - 用 http 開啟（不是安全連線）：請改用 https 網址。這項最先檢查，因為 http 時瀏覽器會把麥克風功能整個隱藏，不檢查的話會被誤判成「沒有麥克風功能」。
  - 瀏覽器沒有開放麥克風（例如 LINE、FB 的內建瀏覽器）：請改用 Safari 或 Chrome。
  - 瀏覽器沒有錄音功能：iPhone 請更新到 iOS 14.5 以上。
  - 沒有麥克風權限、找不到麥克風、麥克風被其他 App 使用（例如通話中），以及其他錯誤，各有自己的訊息。
- 語音辨識在 http 開啟時也會說明需要 https。

### 語音辨識（選用）

- 只在瀏覽器支援時顯示「辨識」按鈕。
- 第一次按下時先說明：辨識由 Chrome 完成，聲音會傳給 Google 處理。按「繼續辨識」才開始收音，按「取消」就不辨識，下次還會再問。
- 辨識中會停止所有播放並停用示範播放和錄音，避免把示範音誤判成學習者的聲音。
- 8 秒逾時；離開題目時一定取消。
- 辨識結果只給正面的參考（哪些字有聽到），不影響評分。

### 學習與存檔

- **打字拼字還沒進今日複習**：只在任務練習出題。也只能考一個純字母的字，有空白或撇號的字（trash can）會被略過。
- **聽力填空、讀招牌／價目、看圖選句、句子填空、讀短文、聽對話答題還沒進今日複習**（2026-11-22；第二幕的三種於 2026-11-23）：`buildReviewQuestions` 沒有改，這六種題型只在任務練習出現。讀招牌、看圖選句、讀短文、聽對話答題沒有複習卡片（`NO_ITEM`），句子填空只有帶 `chunkId` 的才有，要進複習得先決定怎麼排程。
- **看圖選句只有文字選項**（2026-11-22）：多益第 1 大題是聽 4 個聲音選項。現在只有答完後播正確的那一句，錯的句子沒有音檔。
- **聽力填空只認得 -s、-es 的變化形**（2026-11-22）：挖掉的字是教過的單字或它加 -s／-es 才算那個單字。不規則複數、過去式、-ing 還對不到，會是 `NO_ITEM`；第一幕目前沒有這種題目。
- **存檔的 `__proto__` 鍵**（`src/core/save.ts`）：卡片或任務的 id 若是 `__proto__`，會改掉該物件的原型，那一筆資料會悄悄消失。改法：略過這個鍵，或用 `Object.create(null)`，或用正規表示式檢查 id。
- **選回應題可能把正確說法判錯**（`src/learning/questionGen.ts`）：檢查重複選項時沒有考慮詞塊的 `accept` 清單。若另一個詞塊剛好等於某個可接受的說法，會被當成錯誤選項。目前的內容不會觸發。
- **`?debugDate` 的日期解析**（`src/core/save.ts` 的 `resolveNow`）：年份 `0001` 會變成 1901，`2026-02-31` 會變成 3 月 3 日。只影響除錯參數。
- **存檔匯出／匯入還沒接上介面**（`src/core/save.ts`）：接上之前要加匯入代碼的長度上限，並拒絕比目前版本新的存檔（現在會默默降級）。
- **沒有計分題時給 3 顆星**（`src/learning/sessionPlan.ts`、`src/ui/ReviewScreen.tsx`）：答對率被當成 100%。目前的內容不會發生。
