# 學習設計

遊戲採用的學習方法、任務流程、複習排程和獎勵規則。

## 每個任務的流程

1. **看劇情**：NPC 對話一句一句出現，自動播放發音；每句都能重聽、慢速重聽。
2. **認識新詞塊**：新詞塊和新單字一張一張介紹，有發音、慢速、中文和文法小抄。
3. **練習**：題目由易到難（順序見 [vocab-quiz.md](vocab-quiz.md)）：聽音選圖、聽辨挑戰、聽音選字、聽力填空、選回應、讀招牌／價目、看圖選句、句子填空、讀短文、聽對話答題、排句子、打字拼字。聽力填空、讀招牌、看圖選句是 2026-11-22 加的，只有內容裡有寫的任務才會出（第一幕從街道 t6、服飾店 t5、診所 t5 開始）；句子填空、讀短文、聽對話答題是第二幕用的（銀行 t5、社區中心 t4、修車與維修 t5 開始），規則一樣，內容裡沒寫的任務不會出。
4. **跟我說**：每個新詞塊念一次，可以跳過。
5. **結算**：星星、金幣、這次學到的新內容。

每個地點的最後一關是**角色扮演大挑戰**（第 8 個任務，只複習，不教新內容）：

1. **說明**：這次沒有劇本，要自己完成整段對話。
2. **對話**：NPC 的台詞一句一句出現並自動播放。輪到你時，只看前面的對話，把打亂的字塊排成你要說的話；按「看中文」才會出現中文，算用了幫助。答完後，你的那句加入對話，接著換 NPC 說。說明畫面可以打開「跟我說」：每句排完再大聲說一次，和一般的跟我說題一樣不計分、不影響複習排程。
3. **結算**：星星照答對率，金幣和一般任務一樣。每一回合用那句的詞塊排複習。

## 複習排程

### 每個項目一張卡

- 項目 id 是 `chunk:<詞塊 id>`、`word:<單字 id>` 或 `pair:<對比詞 id>`，每個項目在存檔裡有一張 FSRS 卡片。
- 第一次答到某個項目時建立卡片。
- 「跟我說」題不會被評分，也不會影響排程。
- 不屬於任何項目的題目（`NO_ITEM`，`src/learning/questions.ts`，2026-11-22）：讀招牌／價目和看圖選句不是在考某一個詞塊或單字，所以答完只計入這一輪（星星、金幣）和當天的答題數、答對數，不建立卡片，也不會出現在今日複習。
- 聽力填空：挖掉的字是教過的單字時，算那個單字的一次複習；否則算那句台詞的詞塊；都不是時也是 `NO_ITEM`（細節見 [vocab-quiz.md](vocab-quiz.md)）。
- 句子填空：有 `chunkId` 時算那個詞塊的一次複習，沒有時是 `NO_ITEM`。讀短文和聽對話答題一律是 `NO_ITEM`：讀一篇短文或聽一段對話不是某一個詞塊或單字，答完只計入這一輪（星星、金幣）和當天的答題數、答對數。

### 作答怎麼變成 FSRS 評分（玩家不用自己按）

| 作答情況               | 評分  |
| ---------------------- | ----- |
| 答錯                   | Again |
| 答對，但用了慢速或提示 | Hard  |
| 答對                   | Good  |
| 答對而且很快           | Easy  |

「很快」的門檻（`src/learning/sessionPlan.ts`）：

- 4 秒內：聽音選圖／選字、聽辨挑戰、選回應。
- 12 秒內：排句子、打字拼字，以及 2026-11-22 加的聽力填空、讀招牌／價目、看圖選句，和第二幕的句子填空、讀短文、聽對話答題（要聽完一整句、讀招牌或讀幾個句子，本來就比較久）。讀招牌、看圖選句、讀短文、聽對話答題沒有卡片，這個門檻目前對它們沒有作用；句子填空只有帶 `chunkId` 的才有卡片。

### 一次練習只排程一次

同一個詞塊在一次練習裡會出現好幾題。為了不讓連續幾次快答把複習間隔灌得太大：

- 每個項目在一次練習裡**只算一次複習**，以這次練習中**最差的結果**計算。
- 每答一題仍然立刻存檔，重新整理不會遺失進度。
- 重玩已完成的任務時，若卡片還沒到期，複習時間不會被往後推；答錯仍然可以讓它提早回來。

### 今日複習

- 每天最多 20 題，從最逾期的開始。
- 內容裡已經不存在的項目（例如改名或刪除過的詞塊）不列入。
- 複習題型以聽音選圖和排句子為主，還不會出打字拼字、聽力填空、讀招牌／價目、看圖選句、句子填空、讀短文、聽對話答題。
- 時間被調回過去（例如裝置時間修正）時，排程以上次複習時間為準，不會出錯。

## 星星、金幣、連續天數

- **星星**：答對率 90% 以上 3 顆，70% 以上 2 顆，其他 1 顆。「跟我說」不計入。
- **金幣**：每答對一題 5 枚；拿到 3 顆星再加 10 枚。今日複習每答對一題 5 枚。
- **連續天數**：今天或昨天有玩就延續；中間斷了就從頭算，沒有其他懲罰。
