# 產品規格

產品目標、目標玩家、範圍、地點和遊戲機制。

## 目標

一個可愛像素風的網頁英文遊戲，讓**成人初學者**從基礎開始學英文，而且好玩。發音和音樂是核心。玩法本身就是學習方法，不是在題庫外面套一層遊戲皮。

**學習目標：通關後達到多益聽力與閱讀 600 分以上的程度**（約 CEFR B1），難度曲線要非常平滑。完整規劃見 [curriculum.md](curriculum.md)。

## 玩家

- 母語是中文（台灣）的成人。
- 主要玩家：學過學校英文、認得字母和一些單字，但聽不懂、不敢開口。
- 完全零基礎的人也要能從字母和發音開始（「搬家第一天」單元：自我介紹、問拼法、請對方說慢一點，加上聽辨相似的音）。
- 使用情境：通勤或休息時用手機玩，每次約 10 分鐘；也能在電腦上玩。

## 範圍

- 四幕，故事是「生活 → 找工作 → 上班」：
  - 第一幕 新生活（A1 → A2）
  - 第二幕 找工作（A2 → A2+）
  - 第三幕 上班第一年（A2+ → B1）
  - 第四幕 升遷之路（B1 鞏固，目標多益 600 以上）
- 約 42 個地點、360 個任務，總共約 600 個詞塊、2,900 個單字，用字依 NGSL 和 TSL（多益字表）。
- 加入閱讀題和多益形式的題型，聽力和閱讀一起練。
- 2026-11-22 前的目標是「A1 到 A2 入門、10 個地點、500 個單字」，現在是第一幕的範圍。

## 核心概念：搬到英語小鎮生活

玩家剛搬進一座小鎮，居民都說英文。完成生活任務就是在學英文，英文越好，能去的地方越多。整體氣氛是療癒的生活模擬，可愛但不幼稚。

## 地點

每個地點是一個學習單元，約 8 個任務，最後一個是角色扮演大挑戰。下表是第一幕的 10 個地點；第二到第四幕的地點見 [curriculum.md](curriculum.md)。

| #   | 地點         | 核心詞塊與內容                                            | 狀態                                    |
| --- | ------------ | --------------------------------------------------------- | --------------------------------------- |
| 1   | 搬家第一天   | 字母音、自然發音速成、自我介紹、「聽不懂，請再說一次」    | **已做 7 個任務**（角色扮演大挑戰未做） |
| 2   | 咖啡廳       | Can I get…? / For here or to go? / How much is it?        | **已做 7 個任務**（角色扮演大挑戰未做） |
| 3   | 便利商店     | 數字、價格、I'll take it.（How much is it? 在咖啡廳教過） | 未做                                    |
| 4   | 街道與公車站 | Where is…? / How do I get to…? / 方向                     | 未做                                    |
| 5   | 超市與市集   | some/any、可數不可數、Do you have…?                       | 未做                                    |
| 6   | 服飾店       | Can I try this on? / It's too…                            | 未做                                    |
| 7   | 診所與藥局   | I have a… / I feel…                                       | 未做                                    |
| 8   | 餐廳與聚會   | 訂位、點餐、small talk、過去式                            | 未做                                    |
| 9   | 郵局         | 寄包裹、填單、I'd like to send…                           | 未做                                    |
| 10  | 公園與社區   | 週末活動、邀約、Would you like to…?                       | 未做                                    |

原本的「辦公室」和「機場與飯店」移到第三幕（上班第一年）。

咖啡廳是第一個做的地點，用來驗證整個流程；第二個是搬家第一天，在小鎮畫面排在咖啡廳前面。搬家第一天的「聽不懂」改教 "How do you spell that?" 和 "Can you speak more slowly, please?"，因為 "Sorry, can you say that again?" 已經在咖啡廳教過。小鎮畫面上其他地點顯示為「即將開幕」。

## 遊戲機制

| 機制                 | 狀態 | 說明                                                                |
| -------------------- | ---- | ------------------------------------------------------------------- |
| 星星                 | 已做 | 每個任務依答對率給 1 到 3 顆星（規則見 [learning.md](learning.md)） |
| 金幣                 | 已做 | 答對得金幣，目前還沒有地方可以花                                    |
| 連續天數             | 已做 | 中斷不扣分，只是重新計算                                            |
| 連擊                 | 已做 | 連續答對顯示連擊，音效音高跟著升高                                  |
| 愛心                 | 已做 | 3 顆；答錯扣 1 顆；扣完顯示「沒關係，再聽一次」並補滿，任務不會失敗 |
| 任務依序解鎖         | 已做 | 完成上一個任務才能玩下一個                                          |
| 生活任務板           | 未做 | 鎮上布告欄的委託                                                    |
| NPC 好感度與支線     | 未做 | 居民有個性和故事，好感度高會解鎖新劇情                              |
| 小屋布置、換裝、寵物 | 未做 | 金幣的用途                                                          |
| 單字筆記本           | 未做 | 學過的詞塊都能點開聽                                                |
| 數據儀表板           | 未做 | 已學詞塊數、答對率、最常錯的音和文法                                |
| 角色扮演大挑戰       | 未做 | 每個地點的最後一關，自己完成整段對話                                |
