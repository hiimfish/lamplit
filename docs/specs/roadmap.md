## 需要使用者處理的事

1. **在真的手機上玩一次**：目前只用電腦瀏覽器模擬過手機。
2. **測試錄音和語音辨識**：開發用的瀏覽器沒有麥克風，這兩項沒在真實裝置上試過。注意：手機透過區網 http 連線時瀏覽器不允許錄音，要用 HTTPS：開發時執行 `npm run dev:https`（步驟見 [architecture.md](architecture.md) 的「手機上測錄音」），或部署到 GitHub Pages 後測試。
3. **確認 Google 的服務條款**：生成的音檔能不能放進公開的網站和 repo，官方頁面沒寫清楚，上線前一定要確認。
4. **決定 repo 要不要公開**：GitHub Pages 免費方案需要公開。
5. **試玩 2026-11-22 新做的 7 個地點**（街道與公車站到公園與社區）：新的台詞、12 個新角色的發音、7 個小劇場、10 張看圖選句的圖，使用者都還沒看過或聽過。之後每個新地點的發音也都需要人耳確認。
6. **試玩 2026-11-23 新做的第二幕 8 個地點**：沒有人玩過第二幕；台詞沒有真人讀過；8 個小劇場、4 張新的看圖選句的圖、三種新題型的畫面（句子填空、讀短文、聽對話答題）都還沒請使用者看過。
7. **英文內容審閱**：句子最好請英文好的人看過。第一幕後 7 個地點和第二幕的 8 個地點，每個地點寫完後只做過自己的一輪編修，沒有真人或英文流利的人看過。
8. **決定要不要加幕與幕之間的鎖**：規格寫的是一幕接一幕解鎖；現在沒有鎖，第二幕不用等第一幕玩完。要鎖的話，要決定怎麼算「玩完」（見 [curriculum.md](curriculum.md)）。

## 已知問題

- 聽力填空、讀招牌／價目、看圖選句、打字拼字，以及第二幕的句子填空、讀短文、聽對話答題，都還沒進今日複習；讀招牌、看圖選句、讀短文、聽對話答題沒有複習卡片。
- 有空白的單字（trash can）還不能考打字拼字。
- 看圖選句只有文字選項，多益第 1 大題的聲音選項還沒做。
- 手機橫向（844×390）時，聽力填空、讀招牌、看圖選句答完後的回饋比畫面高，要往下捲才看得到全部（2026-11-22 無頭 Chrome 量到多 21～121px；會自動捲到「繼續」）。答題前都放得下。手機直向 390×844 不用捲。
- 第二幕的句子填空答完後的回饋，手機直向（390×844）時社區中心 t2 比卡片高 3 px；手機橫向（844×390）時比卡片高 36 px，和上一項同一類。這些是 2026-11-23 無頭 Chrome 量到的，只量了每種題型的幾個任務，其他任務沒有一一量過。讀短文和聽對話答題在這兩種方向都沒有溢出。
- 瀏覽器語音備援（音檔失敗時）一律用美式口音，英式口音的圖書館員在備援時也是美式。
- 每個地點的任務都播咖啡廳那一首音樂，還沒有各地點自己的音樂。
- 小鎮是一份任務清單，背後的街景只有咖啡廳那條街，沒有每個地點自己的街景。
- 低優先的程式問題：見 [vocab-quiz.md](vocab-quiz.md) 的「待改進」。
- 「水」的像素圖最不容易辨認；三明治和蛋糕的白色部分和背景有點糊在一起。
- 電腦橫向時對話視窗幾乎蓋住整條街，超過三句要往上捲。
- 手機上選回應題的「再聽一次」「慢速」會換到下一行。
- 錄音和辨識時「按鈕是否正確停用」沒有自動化測試（專案沒有模擬瀏覽器的測試環境）。

## 風險

| 風險                                 | 程度 | 對策                                                                      |
| ------------------------------------ | ---- | ------------------------------------------------------------------------- |
| 內容量大，句子要自然道地             | 高   | 內容檢查自動化；上線前請人審閱                                            |
| 成人覺得太幼稚或太像考試             | 高   | 生活模擬包裝、真實情境；每個階段都試玩                                    |
| 從零開始 3 個月到 600 分不一定做得到 | 高   | 衝刺路線有檢查點，跟不上就延長時間，沒有懲罰（見 [sprint.md](sprint.md)） |
| 每個新單字都要畫像素圖               | 中   | 圖鑑式的固定規格（24×24、同一調色盤），有測試檢查每個單字都有圖           |
| 生成音檔的使用條款                   | 中   | 上線前確認                                                                |
| 語音辨識只有部分瀏覽器支援、不一定準 | 中   | 只當額外參考，不影響評分；主要靠錄音比對                                  |
| 換裝置進度不會同步                   | 低   | 之後做存檔匯出／匯入；帳號同步不在範圍內                                  |
