# 聲音規格

發音、背景音樂、音效和音量的規格，以及產生音檔的方式。聲音是這個遊戲的核心，使用者已試聽並確認目前的設定，修改前要先確認。

## 發音

### 聲線

發音音檔用 Google Cloud Text-to-Speech **預先產生**成 mp3，放進網站一起發布。網站本身不需要金鑰，也不會呼叫 Google。

| 用途                             | 聲線                                                                                      | 說明                                                                        |
| -------------------------------- | ----------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| 正常速度（預設，聲線 B）         | Chirp 3 HD：店員 `Achernar`、房東 `Charon`、鄰居 `Aoede`、你／詞塊／單字／對比詞 `Achird` | 使用者覺得最自然；房東的聲線還沒請使用者試聽                                |
| 正常速度（聲線 A，可在設定切換） | Neural2：店員 `C`、房東 `D`、鄰居 `F`、你／詞塊／單字／對比詞 `A`                         |                                                                             |
| 慢速（兩種聲線都一樣）           | Neural2，速度 0.75                                                                        | Chirp 3 HD 的速度設定結果忽快忽慢，試過的慢速版使用者聽起來不自然，所以不用 |

聲線對照表在 `src/audio/voices.ts`；為什麼這樣選，見本文的「聲線決策紀錄」。

### 檔案

- 路徑：`public/audio/<聲線家族>/<音檔 id>.<normal|slow>.mp3`，例如 `public/audio/chirp/cafe.word.latte.normal.mp3`。
- 每句有 Chirp 正常、Neural2 正常、Neural2 慢速三個檔案。咖啡廳共 228 個，搬家第一天共 288 個。2026-11-22 加上兩個單元的 t4～t7 時，新產生 261 個檔案、計費 4,626 字元；同一天加上兩個 t8（角色扮演大挑戰）時，新產生 78 個、計費 1,785 字元。
- 對比詞的兩個字各有自己的音檔：`<單元>.pair.<字的 id>`，例如 `move_in.pair.fan`。
- 產生方式見本文的「產生音檔」。

### 播放規則

- 每次只播一句；播新的一句會停掉上一句。
- 每個音檔網址只下載一次，之後用快取。
- 音檔讀取或解碼失敗時，改用瀏覽器內建語音；但裝置沒有英文語音時寧可不播，也不用中文語音念英文。
- 不符合格式的音檔 id 不會被下載。

## 背景音樂

用 Web Audio 即時合成，沒有音檔，全部原創。風格是安靜的「水晶」感：

- 鈴聲和八音盒音色（正弦波加一點泛音）、柔和的墊音、用延遲做出的餘韻。
- 沒有鼓、沒有低音、沒有方波。
- 整體比最初版本小約 12 dB，存在感降到最低。

| 曲子 | 用在       | 調性           | 速度   | 長度                    |
| ---- | ---------- | -------------- | ------ | ----------------------- |
| town | 標題、小鎮 | C 大調五聲音階 | 66 bpm | 24 小節，約 87 秒才重複 |
| cafe | 咖啡廳任務 | G 大調五聲音階 | 60 bpm | 16 小節，64 秒          |

規則：

- 換曲時淡出淡入約 1.5 秒；同一首重複呼叫不會重新開始。
- **播放發音時，音樂自動壓低到 15%**，發音結束 300 毫秒後回復。
- 分頁在背景停頓後，跳過錯過的音符，不會一次全部播出來。

## 音效

全部即時合成：點擊、答對（連擊越多音高越高，最多升一個八度）、答錯（柔和下滑）、金幣、完成任務。

## 音量

設定頁有三個獨立的音量滑桿：

| 音軌 | 預設 |
| ---- | ---- |
| 音樂 | 25%  |
| 發音 | 100% |
| 音效 | 70%  |

開發伺服器（`npm run dev`）每次載入時音樂一律從 0 開始，避免開發時一直重播；滑桿在當次仍可調整。正式建置會沿用存檔裡的音量。

## 瀏覽器限制

- 瀏覽器要等使用者先點一下才能播聲音，所以標題畫面用「點一下開始」解鎖音訊。
- 接電話、切換 App 或分頁回來後，會自動恢復播放（包含 iOS 的「中斷」狀態）。

## 產生音檔

音檔由 `scripts/gen-audio.mjs` 讀取 `src/data/units/` 的所有單元後產生。網站執行時不呼叫任何 API。

```bash
node --env-file=.env scripts/gen-audio.mjs              # 產生缺少或內容有變的檔案
node scripts/gen-audio.mjs --dry-run                    # 只預演：不連網、不寫檔，列出檔案數和計費字元數
node --env-file=.env scripts/gen-audio.mjs --force      # 全部重做
node --env-file=.env scripts/gen-audio.mjs --only=latte # 只處理路徑含 latte 的檔案
```

- `.env` 需要 `GOOGLE_TTS_API_KEY`（參考 `.env.example`；`.env` 不進版控）。腳本不會印出金鑰。
- 快取：`public/audio/manifest.json` 記錄每個檔案的雜湊（由文字、聲線和速度算出）。雜湊相同且檔案存在就跳過。
- 每個檔案先寫到暫存檔再改名，並在每個檔案成功後立刻更新清單；中途中斷不會留下壞檔，也不會重複付費。
- 有任何請求失敗時，結束碼不是 0。
- 新增單元後執行一次，只會產生新的檔案；產生的 `public/audio/` 要一起提交。

### 費用

依 2026-11-22 查閱的 Google 官方定價頁：

| 聲線        | 免費用量   | 超過後每 100 萬字元 |
| ----------- | ---------- | ------------------- |
| Chirp 3: HD | 100 萬字元 | US$30               |
| Neural2     | 100 萬字元 | US$16               |

- 定價頁沒有寫明免費用量是不是每月計算，請在 Google Cloud 的帳單頁確認。
- 咖啡廳單元約 370 字元，三種版本共約 1,110 字元；整個遊戲估計 15 到 30 萬字元，在免費用量內。
- **還沒確認**：生成的音檔能不能放進公開的網站和 repo。官方頁面沒寫，上線前要看 Google Cloud 服務條款。

## 聲線決策紀錄

2026-11-22 的實測與試聽結果：

| 項目                        | Neural2                              | Chirp 3 HD                                            |
| --------------------------- | ------------------------------------ | ----------------------------------------------------- |
| 慢速（0.75）長度 ÷ 正常長度 | 句子穩定 1.31 到 1.33（理論值 1.33） | 0.72 到 2.50，同一句重複請求差很多                    |
| 正常速度聽感（使用者）      | 比較像標準語音合成                   | 最自然                                                |
| 慢速聽感（使用者）          | 可接受                               | 試過「重試到長度落在 1.25 到 1.9 倍」的版本，仍不自然 |
| 單獨字母音（SSML 音標）     | 0.7 到 0.84 秒，是否念對未確認       | 0.17 到 0.46 秒，幾乎沒念                             |
| 檔案                        | 64 kbps                              | 32 kbps                                               |

結論：正常速度預設用 Chirp 3 HD，慢速一律用 Neural2。字母音的教法先用「音加例字」（例如 b, buh, ball），不依賴單獨音素。
