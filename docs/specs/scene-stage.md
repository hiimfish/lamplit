# 劇情小劇場

任務開頭「先看看發生什麼事」時出現的小畫面，之後的新詞塊和練習也一直顯示。第一幕十個地點各有一個場景：咖啡廳是店員和你站在櫃檯前，搬家第一天是房東（或鄰居）和你在新家玄關，便利商店是店員在櫃檯後面、你站在飲料冰櫃前；街道是公車站，超市與市集是蔬果攤，服飾店、診所、餐廳、郵局是店裡面，公園是池塘邊的步道。第二幕的八個地點也各有一個場景：銀行是櫃員櫃檯，社區中心是電腦教室，圖書館是借書櫃檯，修車與維修有兩張背景（你家廚房和修車廠），就業服務站是顧問的辦公桌，履歷是電腦教室裡的長桌，面試是 Harbor Trading 的辦公室，上班前一天是你家客廳（主管打來的電話有一張電話畫面的背景）。第三幕「上班第一年」的十二個地點也畫好了場景（人資辦公室、辦公室座位、電話、Email、會議室、會客桌、倉庫、客服、機場、飯店、商展攤位、派對會場，其中四個有第二張背景），但第三幕還沒有單元、台詞和音檔，遊戲裡還看不到。每個任務只出現有台詞的角色。誰說話誰就動，部分台詞會有道具動作。手機直向時填滿上方整個街景區；電腦橫向時是左邊整個高度的一欄，任務卡片在右邊。

狀態：**已做**（第一、二幕共 18 個地點都有）。咖啡廳、搬家第一天、便利商店在 2026-11-22 用手機直向和電腦橫向的瀏覽器畫面實際操作過；「減少動態」只確認了 CSS 規則有載入，沒有實際用系統設定測試。街道、超市與市集、服飾店、診所與藥局、餐廳與聚會、郵局、公園與社區這 7 個是 2026-11-22 新做的，第二幕的 8 個是 2026-11-23 新做的，這 15 個都還沒請使用者看過。第二幕的 64 個任務在無頭 Chrome（手機直向 390×844）都玩到了結算畫面，console 沒有錯誤；手機橫向 844×390 只試了四個任務（見 [roadmap.md](roadmap.md)）。

第三幕的 12 個場景和 9 張新角色圖是 2026-11-23 畫的，**畫好了但還沒有任何單元使用**：`src/data/units/` 裡沒有第三幕的單元，所以遊戲裡還看不到，也還不能實際操作；目前通過的是 `tests/stageArt.test.ts` 的自動檢查。使用者還沒有在遊戲裡看過。

## 目的與原則

- **輔助理解，不取代文字**：聊天泡泡、中文、「慢速」按鈕都維持原樣，學習內容還是靠文字和聲音。小劇場只是讓人一眼看出「誰在跟誰說話、在做什麼」。
- **純裝飾**：不能按、不能聚焦，所以不違反「能按的東西都是有框的按鈕」。
- **安靜**：和街景一樣大部分時間靜止，只有說話和道具動作時才動。
- 系統設定「減少動態」時完全靜止（見下方）。

### 舞台設定

- `src/art/stage/config.ts`（2026-11-22 新增）放共用的型別和「你」：
  - `StageConfig`：一個場景的整份設定：`paint`（背景繪製函式，任意大小）、選填 `backdrops`（見下）、`cast`（每個 `role` 的角色圖、位置、站哪一邊，選填 `clipBottom` 和 `beside`）、`want`／`ask`（左右兩邊泡泡的位置）、`rest`（左右兩邊道具放的位置）。
  - `backdrops?: Partial<Record<Role, (p: Painter, w: number, h: number) => void>>`：同一個地點的任務發生在兩個地方時（修車與維修：房東在你家廚房、師傅在修車廠；上班前一天：主管在電話裡、鄰居在你家客廳），讓某個 NPC 的場景改用另一張背景。規則：看這個任務場景裡第一句不是你說的台詞，由誰說（`sceneNpc`）；`backdrops` 有那個角色就用它畫背景，沒有就用 `paint`；場景裡沒有 NPC 台詞也用 `paint`。沒設 `backdrops` 的場景完全照舊。每個 `backdrops` 的函式和 `paint` 一樣：任意大小、只用調色盤顏色、整數座標、不超出舞台、同樣輸入畫出同樣畫面，測試對每一張都檢查。背景圖快取的鍵含用的是哪一張（`單元:角色:寬x高`），所以兩張背景不會互相蓋掉。選擇的程式是 `stageState.ts` 的 `paintFor(config, scene, backdrop)`（第三個參數是任務的 `backdrop`，見下）；任務畫面和小鎮畫面都用它（小鎮畫面顯示的是一個真的任務的場景，所以跟著那個任務選背景）。
    範例：`backdrops: { landlord: paintKitchen }`，`paint`（`paintShop`）畫修車廠。第二幕只有修車與維修和上班前一天用 `backdrops`。第三幕有四個場景用：電話與留言（`client`：客戶在電話畫框裡）、客戶服務（`customer`：顧客在電話畫框裡）、機場（`coworker`：登機門）、飯店（`manager`：房間裡的語音留言）。30 個場景合計 36 張背景。

    任務指定背景（`tasks[].backdrop`，2026-11-23）：任務可以自己決定用哪一張，不管誰先說話。寫 `backdrops` 裡的一個角色 key（例如機場 t5 地勤在登機門說話，寫 `"backdrop": "coworker"` 用登機門那張；飯店的語音留言房間寫 `"backdrop": "manager"`），或寫 `"main"` 強制用一般的 `paint`（例如機場 Dan 先說話、但人在報到大廳的任務）。不寫就照上面的規則看第一個說話的 NPC。寫的 key 那個場景沒有時，也用 `paint`。程式是 `stageState.ts` 的 `backdropKey(config, scene, backdrop)` 和 `paintFor(config, scene, backdrop)`；`SceneStage` 多一個 `backdrop` 屬性，任務畫面和小鎮畫面都傳 `task.backdrop`，背景快取的鍵也照它算。`validateUnit` 檢查值是合法角色或 `main`，`tests/stageArt.test.ts` 再檢查每個有寫的任務（`main` 除外），key 都在那個單元小劇場的 `backdrops` 裡。這只換背景，角色還是照原本的規則出現（有台詞的 NPC 才畫）。
  - `StageSide`：`left` 或 `right`。

### 只畫這個任務的角色

- 每個單元有一份 `cast`（全部可能出場的角色），但每個任務只畫：你（`guide`，一定在）＋這個任務的 `scene` 裡至少有一句台詞的 NPC。所以搬家第一天的任務 1–5 只有房東，任務 6、7 只有鄰居，t8（角色扮演大挑戰）兩個都有。

## 動作

### 說話

- 說話的人以 `steps()` 上下跳 1 像素，從聲音開始播放到 `playAudio()` 結束為止（`playAudio` 會在音檔播完時 resolve）。
- 點泡泡重聽或按「慢速」時也會動，動的是那一句的說話者。
- 換下一句時，上一句的跳動立刻停止。
- 新詞塊和練習時也一樣：播出誰的聲音，誰就跳動，播完或換題就停。詞塊、單字、對比詞都是「你」的聲音，所以是你在動；選回應題先是店員或房東說那句話，作答後播出回應時換你動。
- 跳動的角色和錄音用的聲音來自同一份對照（`unitToAudioItems` 的 `role`），所以一定對得上。
- 音檔讀取失敗、改用瀏覽器內建語音時，角色不會跳動（瀏覽器語音不會通知播完的時間）。

### 道具動作

台詞可以加一個選填欄位 `stage`，有三種動作：

| `act`  | 需要 `item` | 畫面                                                                                                                           |
| ------ | ----------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `want` | 要          | 說話者頭上冒出想法泡泡，裡面是該單字的像素圖（24×24，1 倍）；下一句出現時消失                                                  |
| `ask`  | 不可以有    | 說話者頭上出現「?」泡泡；下一句出現時消失                                                                                      |
| `give` | 要          | 單字圖卡從說話者那邊沿著櫃檯滑到對方那邊，之後留在櫃檯上，直到這個任務結束；同一邊的第二個道具往中間再挪 14 像素，不會疊在一起 |

- 單字圖沿用 `ItemIcon`；沒有像素圖的單字顯示 emoji 備用圖。
- 泡泡出現時用 2 格動畫往上彈出（160 毫秒）；`give` 滑動 600 毫秒，每一格移動 1 個邏輯像素。
- 每個任務的舞台都從空的狀態開始，不會帶到下一個任務。
- 劇情結束後（新詞塊、練習），舞台停在劇情最後的樣子：角色站在原位（只有播音檔時說話的人會跳）、遞過的東西留在櫃檯上、沒有泡泡（`stageAfter`）。只是裝飾，不會提示答案。

## 版面

舞台滿版、蓋在街景上（`src/ui/stage/stageArea.ts`），倍率一定是整數。背景圖把舞台區域往上取整到整數個舞台像素，貼齊左下角，所以每個像素都對齊裝置像素。

- **直向（手機）**：填滿整個街景區，蓋住街景。下方的紙面板只放對話，空間和沒有舞台時一樣。390×844 的手機是 2 倍；街景區最小 240×120 時是 1 倍。
- **橫向（電腦）**：舞台是左邊整個高度的一欄，右緣有 1 像素墨線。任務卡片（劇情、新詞塊、練習）在右邊滿版：從舞台右緣填到螢幕右邊和上下，沒有外框和陰影，和手機的紙面板一樣，看不到街景。
  - 卡片通常保留 230 邏輯像素寬，舞台用剩下的寬度（最多 256），倍率最多 2 倍。
  - 小螢幕時卡片可以縮到 190，讓舞台維持 2 倍（800×450 也是 2 倍）。1366×768 和 1280×720 都是 2 倍。
  - 舞台比核心窄時，核心左右兩邊平均裁掉（角落盆栽、半台咖啡機）。角色、泡泡和道具都在核心中間 96 像素內，所以一定看得到。
  - 使用者試過在右邊露出的街景上加黑色半透明層，後來改成卡片滿版、不加黑色層。
- 任務標題列右邊預留「先回小鎮」的位置，標題在剩下的空間置中，太長時換行，不會跑到按鈕底下。
- 整個任務（劇情、新詞塊、練習）都顯示舞台，版面不變；離開任務（結算或「先回小鎮」）時舞台消失，街景恢復。複習畫面的題目來自不同單元，不顯示舞台。
- 卡片較窄（800×450 時 208 邏輯像素）時沒有橫向超出；新詞塊和答題後的回饋有時要捲動，和原本置中卡片的情況差不多。
- 做法：`TaskScreen` 用 `TaskStage` 把舞台用 portal 放進 `#frame`（同時傳入 `task.scene`，用來決定畫哪些角色），並在 `.flow` 加 `has-stage`。橫向時在 `#frame` 設 `--stage-w`，讓 `flow.css` 把卡片往右推。`SceneStory` 用 `onShown` 回報顯示到第幾句；誰在說話一律看 `nowPlaying`（正在播的音檔）並用 `speakerOf` 找出說話的角色，劇情、新詞塊、練習、角色扮演都一樣。

使用者 2026-11-22 試看後的要求依序是：從對話框裡移到上方；改成滿版，電腦版也放上方；電腦版看起來怪，改成左右兩欄；新詞塊和練習也顯示舞台，版面和劇情一致。試過的電腦版上方橫條（高度 32%、1 倍）角色太小、對話只放得下一句半，已放棄。

## 減少動態

- 角色完全靜止，說話時不跳動。
- 泡泡直接出現，沒有彈出動畫。
- `give` 不滑動，圖卡直接出現在終點。

## 無障礙

- 舞台整塊加上 `aria-hidden="true"`，不能聚焦。
- 所有資訊本來就在泡泡裡，螢幕閱讀器和鍵盤操作完全不變。

## 內容格式

`scene[]` 的每句台詞可以加 `stage`：

```json
{
  "id": "t1_2",
  "role": "guide",
  "speaker": "player",
  "en": "Can I get a latte, please?",
  "zh": "可以給我一杯拿鐵嗎？",
  "chunkId": "can_i_get",
  "stage": { "act": "want", "item": "latte" }
}
```

內容檢查（`src/content/validate.ts`）：

- `act` 只能是 `want`、`ask`、`give`。
- `want` 和 `give` 一定要有 `item`，而且必須是同一個單元裡的單字 id。
- `ask` 不能有 `item`。

咖啡廳單元的提示：

| 台詞 | 內容                           | `stage`         |
| ---- | ------------------------------ | --------------- |
| t1_2 | Can I get a latte, please?     | `want` latte    |
| t3_1 | How much is it?                | `ask`           |
| t3_3 | Sorry, can you say that again? | `ask`           |
| t3_4 | Six fifty. Here you go.        | `give` sandwich |

上表是 t1～t3 的提示。咖啡廳現在共有 22 句台詞有提示（t4～t8 也有：咖啡、糖、小杯、餅乾、桌子、座位、書）；其他台詞只有說話動作。任務 2 沒有適合的道具（缺外帶杯的圖），沒有加。

第一幕十個地點合計 239 句台詞有道具提示（全部 495 句）。第二幕八個地點合計 73 句（全部 490 句）：銀行 10、社區中心 10、圖書館 8、修車與維修 11、就業服務站 9、履歷 9、面試 13、上班前一天 3。第三幕還沒有台詞，所以還沒有道具提示。
