# 畫面流程

畫面之間怎麼切換、每個畫面有什麼，以及無障礙要求。

```
標題 → 小鎮 ─┬→ 任務：劇情 → 新詞塊 → 練習 → 結算 → 小鎮
             ├→ 今日複習 → 結算 → 小鎮
             └→ 設定（疊在小鎮上）
```

## 標題

- 遊戲名稱、「點一下開始」。
- 點下去會解鎖瀏覽器的音訊、播放開始音效、進入小鎮。
- 橫向時標題在上、按鈕在下，中間留給咖啡廳。

## 小鎮

- 金幣、連續天數、「設定」按鈕。
- 「今日複習（N）」：N 是今天到期的題數，0 時停用。
- 每個地點一段任務清單，搬家第一天在前、咖啡廳在後：已完成的顯示星星，下一個顯示「新任務」，其他顯示鎖頭和「先完成上一關」。每個地點的第一個任務都開放。
- 「即將開幕」：其他地點的名稱，只是資訊。

## 任務

1. **劇情**：小劇場（咖啡廳是店員和你在櫃檯前，搬家第一天是房東或鄰居和你在新家玄關，只畫這個任務有說話的角色），說話的人會動；手機填滿上方的街景區，電腦是左邊一欄、任務卡片在右邊；新詞塊和練習時小劇場停在劇情最後的畫面，版面不變，播音檔時說那句話的人會動（規格見 [scene-stage.md](scene-stage.md)）；台詞一句一框依序出現，每句自動播放；每句旁邊有「慢速」；下方有「中文：開／關」和「下一句」（最後一句後變成「認識新詞塊」）。
2. **新詞塊**：一張卡一個詞塊或單字，有「聽發音」「慢速」、中文和文法小抄，按「下一張」。
3. **練習**：上方有進度（例如 3 / 7）、連擊、愛心（●○）；題型見 [vocab-quiz.md](vocab-quiz.md)。
4. **結算**：星星、答對題數、金幣、學到的新內容；「回小鎮」或「再玩一次」。

標題列右邊的「先回小鎮」可以隨時離開，進度在每答一題時就已存檔。

## 今日複習

和練習題相同的介面，結束後顯示答對題數和金幣。

## 設定

- 聲線 A（Neural2）／聲線 B（Chirp 3 HD，預設），附說明「慢速重播一律使用聲線 A（Neural2）」。
- 音樂、發音、音效三個音量滑桿。
- 「試聽」「試聽（慢速）」。
- 「顯示中文：開／關」。
- 「關閉」。

## 無障礙要求

- 頁面語言是繁體中文；所有英文內容都標 `lang="en"`，讓螢幕閱讀器用英文念。
- 對話框是真正的按鈕，鍵盤按 Enter 或空白鍵可以重聽。
- 設定是對話框：開啟時焦點移進去，Tab 不會跑到後面，按 Esc 關閉，關閉後焦點回到「設定」。
- 換畫面時焦點移到新畫面的標題；答題後焦點移到「繼續」，對錯會被讀出來。
- 允許雙指縮放；手機上的主要按鈕至少 44px 高。
- 對錯不只靠顏色表示。
- 尊重系統的「減少動態」設定。

## 除錯參數

| 網址參數                | 作用                                                                               |
| ----------------------- | ---------------------------------------------------------------------------------- |
| `?debug`                | 左下角顯示版面資訊（方向、放大倍率、邏輯畫面大小）                                 |
| `?debugDate=YYYY-MM-DD` | 把「今天」當成指定日期，用來測試隔天的複習；會使用獨立的除錯存檔，不影響真正的進度 |
