# 畫面流程

畫面之間怎麼切換、每個畫面有什麼，以及無障礙要求。

```
標題 → 小鎮 ─┬→ 任務：劇情 → 新詞塊 → 練習 → 結算 → 小鎮
             ├→ 角色扮演大挑戰（每個地點的最後一個任務：第一、二幕是第 8 個，第三幕是第 9 個）：說明 → 對話 → 結算 → 小鎮
             ├→ 今日複習 → 結算 → 小鎮
             └→ 設定（疊在小鎮上）
```

## 標題

- 遊戲名稱、「點一下開始」。
- 點下去會解鎖瀏覽器的音訊、播放開始音效、進入小鎮。
- 橫向時標題在上、按鈕在下，中間留給咖啡廳。

## 小鎮

2026-11-22 改成三層（幕 → 地點 → 任務），每一層都放得進一個畫面，不用往下捲。改之前是一份 80 個任務的長清單，手機要捲 6 個多畫面。

**上方的場景區**（手機在上方，電腦是左邊一欄）顯示你現在在哪裡：

- 場景：這個地點的小劇場背景，站著主角和下一關會說話的角色，不會動。看幕的總覽時是「繼續」要去的地點；打開一個地點時是那個地點；還沒開的幕沒有場景，露出原本的傍晚街景。
- 場景左上角一塊資訊：金幣、連續天數。右上角是「設定」按鍵。
- 場景下面是兩行的名牌（墨色底）：
  - 總覽：「第一幕 新生活」和這一幕的星星（例如 ★ 32/240）；第二行是「下一關：咖啡廳・冰的，不加糖」，全部玩過是「這一幕全部完成了！」，還沒開的幕是「即將開幕」。
  - 地點：「第一幕 咖啡廳」和這個地點的星星（★ 6/24）；第二行是英文名稱和「完成 3/8」。

**下方的面板**（電腦是右邊）：

- 總覽：
  - 一排四個幕的按鍵（第一幕到第四幕），選中的是 lamp 底色；還沒有內容的幕用虛線框，仍然可以按進去看之後會開的地點。
  - 「今日複習（N）」：N 是今天到期的題數，0 時停用。旁邊是「繼續」（還沒玩過任何任務時顯示「開始」），直接開名牌上寫的那一關；這一幕沒有新任務時停用。電腦上這兩個按鍵放在左邊名牌的下面。
  - 這一幕的地點，兩欄的格子，一格一個按鍵：編號、名稱，下面是星星（★ 9/24），還沒玩過的顯示「新地點」。「繼續」要去的那一格是 lamp-tint 底色。還沒做的地點不是按鍵，是虛線框加鎖頭和名稱。
- 地點：「回第一幕」按鍵（電腦上在左邊名牌的下面），下面是這個地點的 8 個任務（第三幕 9 個），一個任務一個按鍵。已完成的顯示星星，下一個顯示「新任務」，其他顯示鎖頭和「先完成上一關」。每個地點的第一個任務都開放。

其他規則：

- 第一次進小鎮時打開「繼續」所在的那一幕；之後記得你上次看的幕和地點（只記在這次開啟期間），從任務回來會回到同一個畫面。
- 「繼續」的順序：先接著上次玩的地點，那裡沒有新任務了就照遊玩順序找第一個還沒玩過的任務。
- 四幕和各幕的地點寫在 `src/content/acts.ts`：第一幕 10 個、第二幕 8 個、第三幕 12 個（三幕都做完了），第四幕 12 個（還沒做）。`src/data/units/` 有同樣 id 的單元檔，那一格就會自動變成可以玩；測試會檢查每個單元檔都列在某一幕裡。
- 高度不到 660px 的直向畫面（舊手機，或瀏覽器工具列很高時），幕的按鍵、「回第一幕」和地點格子會矮一點，讓 10 個地點和 8 個任務仍然放得下；第三幕是 12 個地點、9 個任務，這個高度下放不放得下還沒量過。
- 每個地點的任務都播同一首 cafe 音樂（見 [audio.md](audio.md)）。

## 任務

1. **劇情**：小劇場（第一到三幕共 30 個地點各有一個場景，例如咖啡廳是店員和你在櫃檯前，搬家第一天是房東或鄰居和你在新家玄關，街道是公車站，公園是池塘邊的步道，銀行是櫃員櫃檯，修車與維修的任務會在你家廚房和修車廠之間換背景；只畫這個任務有說話的角色），說話的人會動；手機填滿上方的街景區，電腦是左邊一欄、任務卡片在右邊；新詞塊和練習時小劇場停在劇情最後的畫面，版面不變，播音檔時說那句話的人會動（規格見 [scene-stage.md](scene-stage.md)）；台詞一句一框依序出現，每句自動播放；每句旁邊有「慢速」；下方有「中文：開／關」和「下一句」（最後一句後變成「認識新詞塊」）。
2. **新詞塊**：一張卡一個詞塊或單字，有「聽發音」「慢速」、中文和文法小抄，按「下一張」。
3. **練習**：上方有進度（例如 3 / 7）、連擊、愛心（●○）；愛心用完補滿時，連擊的位置改顯示「沒關係，再聽一次」，不多佔一行；題型見 [vocab-quiz.md](vocab-quiz.md)。打字拼字題用畫面上的字母鍵盤，不叫出系統鍵盤，所以頁面不會被擠小。一個任務的題目順序是：聽音選圖 → 聽辨挑戰 → 聽音選字 → 聽力填空 → 選回應 → 讀招牌／價目 → 看圖選句 → 句子填空 → 讀短文 → 聽對話答題 → 排句子 → 打字拼字 → 跟我說（任務沒有的題型就跳過）。2026-11-22 新增的三種畫面（第一幕就有），以及 2026-11-23 第二幕開始用的三種：
   - **聽力填空**：「聽聽看，空格裡是哪個字？」。一句台詞自動播放，英文顯示在框裡、少一個字；旁邊有「再聽一次」「慢速」；下面 3～4 個字的按鍵。答完空格填上正確的字。
   - **讀招牌／價目**：「看招牌，回答問題」。一塊深色招牌（標題和幾行字，價錢靠右）、一個英文問題（中文照設定顯示）、2～4 個答案按鍵。沒有聲音。
   - **看圖選句**：「看圖，哪一句說得對？」。一張像素圖，下面 2～4 個英文句子，一行一個按鍵。答完播正確的句子；「顯示中文」開著時，正確的那句和你選的那句下面才出現中文，其他句子不顯示。
   - **句子填空**：「選出最適合放進空格的字」。一個英文句子，中間一個有框的空格；下面 3～4 個字或短語的按鍵。選了之後馬上填進空格：對了空格變綠色；錯了，錯的字留在句子裡加刪除線，正確的填在旁邊。整句的中文只在答完後出現（不管「顯示中文」）。沒有聲音，沒有動畫。
   - **讀短文**：「讀短文，回答問題」。一張紙條放簡訊、傳單、公告、廣告、表格或 email（80 個字以內），下面是英文問題（中文照設定顯示）和答案按鍵；同一篇有兩題時標「第 1／2 題」。手機直向放不下時，紙條在框內捲動，下面還有字時顯示「▼ 還有」；橫向時短文在左、問題在右。答完把答案所在的那一行標出來。沒有聲音。
   - **聽對話答題**：「聽對話，回答問題」，上面有「再聽一次」。對話自動播放，每句接著播，不顯示文字，只有兩個說話者的名牌（正在說的標 ▶）和「第 2／5 句」；播完才出現問題和答案按鍵。答完顯示整段對話，一句一框，每句旁邊有「慢速」，點一句可以單獨重聽。
   - **第三幕的四種新題型**（2026-11-23）：**文法填空**的畫面和句子填空一樣，提示是「文法填空：選出正確的形式」，4 個選項是同一個字的不同形式。**聽獨白答題**和聽對話答題用同一個畫面，提示是「聽獨白，回答問題」，只有一個說話者的名牌。**聽對話答題加圖表**在提示下面放一張文字表格，聽的時候和答題的時候都看得到，表格不唸出來。**段落填空**：一張紙條放 email、公告或訊息，有 2～4 個編號空格，一格一格問；問到的空格有框，前面的空格填上正確答案（綠框），下面是 4 個答案按鍵，最後一格答完才顯示整篇的中文；內文太長時在框內捲動，橫向時內文和答案並排。直向 390×844 走過全部 108 個任務，答題前沒有東西超出畫面；橫向 844×390 的對話加圖表在答題前超出 27 px，還沒修。
4. **結算**：星星、答對題數、金幣、學到的新內容；「回小鎮」或「再玩一次」。

## 角色扮演大挑戰

每個地點的最後一關，只複習。小劇場和一般任務一樣。

1. **說明**：「換你上場」、這次沒有劇本，以及要說幾句；可以切換「跟我說：關／開」（預設關），再按「開始」。
2. **對話**：上面是對話紀錄（和劇情同一種框，可以重聽、慢速），NPC 的台詞一句一句出現並自動播放；下面是排句子題，提示是「換你說：把單字排成你要說的話」，有進度、連擊、愛心。中文要按「看中文」才出現，答完就收起這個按鍵（那句會加入對話紀錄）。答完按「繼續」，你的那句加入對話，接著播 NPC 的下一句。對話紀錄比劇情矮，會自動捲到最新的一句。打開「跟我說」時，每句排完後你的那句先加入對話，下面換成跟我說題（大聲說說看、錄音、辨識），按「我說完了」或「現在不方便說話」後才播 NPC 的下一句；進度的總數變成兩倍（例如 2 / 16）。
3. **收尾**：「你完成了整段對話！」，顯示整段對話並播放最後的 NPC 台詞；下方有「中文：開／關」和「看結果」。
4. **結算**：和一般任務一樣，但沒有「學到的新內容」。

標題列右邊的「先回小鎮」可以隨時離開，進度在每答一題時就已存檔。

## 今日複習

和練習題相同的介面，結束後顯示答對題數和金幣。只會出聽音選圖／選字、排句子和聽辨挑戰；打字拼字、聽力填空、讀招牌／價目、看圖選句、句子填空、讀短文、聽對話答題還不會出現在這裡。

## 設定

- 聲線 A（Neural2）／聲線 B（Chirp 3 HD，預設），附說明「慢速重播一律使用聲線 A（Neural2）」。
- 音樂、發音、音效三個音量滑桿。
- 「試聽」「試聽（慢速）」。
- 「顯示中文：開／關」。
- 「開發模式（所有關卡都能玩）：開／關」：只在開發伺服器（`npm run dev`、`npm run dev:https`）出現，打開後小鎮的所有任務都開放，小鎮的總覽會提示正在用開發模式。正式版不顯示，也不理會存下來的設定。
- 「關閉」。

## 無障礙要求

- 頁面語言是繁體中文；所有英文內容都標 `lang="en"`，讓螢幕閱讀器用英文念。
- 對話框是真正的按鈕，鍵盤按 Enter 或空白鍵可以重聽。
- 設定是對話框：開啟時焦點移進去，Tab 不會跑到後面，按 Esc 關閉，關閉後焦點回到「設定」。
- 換畫面時焦點移到新畫面的標題；答題後焦點移到「繼續」，對錯會被讀出來。
- 允許雙指縮放；手機上的主要按鈕至少 44px 高。
- 對錯不只靠顏色表示。
- 尊重系統的「減少動態」設定。

## 除錯參數

| 網址參數                | 作用                                                                               |
| ----------------------- | ---------------------------------------------------------------------------------- |
| `?debug`                | 左下角顯示版面資訊（方向、放大倍率、邏輯畫面大小）                                 |
| `?debugDate=YYYY-MM-DD` | 把「今天」當成指定日期，用來測試隔天的複習；會使用獨立的除錯存檔，不影響真正的進度 |
