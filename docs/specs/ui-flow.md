# 畫面流程

畫面之間怎麼切換、每個畫面有什麼，以及無障礙要求。

```
標題 → 小鎮 ─┬→ 任務：劇情 → 新詞塊 → 練習 → 結算 → 小鎮
             ├→ 角色扮演大挑戰（每個地點的最後一個任務：第一、二幕是第 8 個，第三幕是第 9 個）：說明 → 對話 → 結算 → 小鎮
             ├→ 幕結業考（小鎮每幕的最後一格）：總覽 → 每段作答 → 成績 → 重做錯題 → 小鎮
             ├→ 今日複習 → 結算 → 小鎮
             ├→ 每日目標 → 文法快練 → 結算 → 小鎮
             └→ 設定（疊在小鎮上）
```

## 標題

- 遊戲名稱、「點一下開始」；玩過任務或考過跳級考以後寫「點一下繼續」，下面一張小紙條寫要接著玩的「地點・任務」（2026-11-25）。
- 點下去會解鎖瀏覽器的音訊、播放開始音效，然後進小鎮，停在下一個沒玩過的任務所在的那一幕（`continueTarget`：跳級打開的幕優先，跳過的幕排最後），那個地點格子是亮的。原本會直接進那個任務，2026-11-25 使用者改成只進小鎮。
- 橫向時標題在上、按鈕在下，中間留給咖啡廳。

## 小鎮

2026-11-22 改成三層（幕 → 地點 → 任務），每一層都放得進一個畫面，不用往下捲。改之前是一份 80 個任務的長清單，手機要捲 6 個多畫面。

**上方的場景區**（手機在上方，電腦是左邊一欄）顯示你現在在哪裡：

- 場景：這個地點的小劇場背景，站著主角和下一關會說話的角色，不會動。看幕的總覽時是「下一關」要去的地點；打開一個地點時是那個地點；還沒開的幕沒有場景，露出原本的傍晚街景。
- 場景左上角一塊資訊：金幣、連續天數。右上角是「每日目標」和「設定」按鍵。
- 場景下面是兩行的名牌（墨色底）：
  - 總覽：「第一幕 新生活」和這一幕的星星（例如 ★ 32/240）；第二行是「下一關：咖啡廳・冰的，不加糖」，全部玩過是「這一幕全部完成了！」，還沒解鎖的幕是「玩完第N幕或考過跳級考就會打開」，還沒開的幕是「即將開幕」。
  - 地點：「第一幕 咖啡廳」和這個地點的星星（★ 6/24）；第二行是英文名稱和「完成 3/8」。

**下方的面板**（電腦是右邊）：

- 總覽：
  - 一排四個幕的按鍵（第一幕到第四幕），選中的是 lamp 底色；還沒有內容的幕用虛線框，仍然可以按進去看之後會開的地點。還沒解鎖的幕也可以按進去看（讀螢幕軟體會唸「未解鎖」）。
  - 場景右上角是「每日目標 x/y」、「進度」和「設定」三個小鍵。「進度」原本只能從每日目標最下面進去，2026-11-25 使用者覺得藏太深，加到小鎮上方；之後使用者把每日目標裡的「進度」鍵拿掉，進度只從小鎮上方進去，返回鍵寫「回小鎮」。直拿手機時左邊的「金幣／連續」會排成兩行。
  - 幕的畫面原本在幕的按鍵下面有「今日複習（N）」和「下一關」（還沒玩過任務時是「開始第一關」，一幕玩完是「第N幕結業考」）。2026-11-25 使用者拿掉了這兩顆：今日複習在「每日目標」裡，下一關是亮起來的地點格子、名牌上寫的「下一關：地點・任務」、標題畫面的「點一下繼續」和任務結算的「下一關」，結業考從地點格子最後的結業考格子進去。電腦上在幕的畫面按 Enter 仍然開名牌寫的那一關（沒有新任務時是結業考）。之後放過一次場景右下角的「開始」，又改成**選關面板**（2026-11-25，使用者的決定）：平常卡片只有一張「下一關」卡（第幾幕和星星、下一關的地點和任務、一顆大的「開始」（一幕玩完時是「開始結業考」）和「選關」）；按「選關」才出現幕的按鍵和地點格子，上面一顆「收起選關」（Esc）。進到地點後 Esc 回到選關，再按 Esc 收起。卡片在那塊區域垂直置中。進到地點後「回第N幕」照舊在任務清單上面。
  - 這一幕的地點，兩欄的格子，一格一個按鍵：編號、名稱，下面是星星（★ 9/24），還沒玩過的顯示「新地點」。「下一關」要去的那一格是 lamp-tint 底色。還沒做的地點不是按鍵，是虛線框加鎖頭和名稱。
  - **幕的鎖**（2026-11-24）：前一幕的每個任務都至少玩過一次（分數不限），下一幕才打開。還沒打開的幕，地點也是虛線框加鎖頭，場景下的名牌寫「玩完第一幕或考過跳級考就會打開」，「下一關」停用。格子上方原本也寫「先玩完第一幕（62／80）才能進這一幕。」，和名牌重複，2026-11-25 拿掉，只留跳級考的提示和按鍵。存檔裡已經玩過某一幕的任務，那一幕就算打開（舊存檔不會被鎖回去）。開發模式全部打開。只鎖小鎮畫面，測試工具直接進任務不受影響。
  - **地點的鎖**（2026-11-24）：打開的幕裡，只有第一個地點一開始就能玩；一個地點的每個任務都至少玩過一次，下一個地點才打開，所以「新地點」只會出現在剛打開的那一格。還沒打開的地點是虛線框加鎖頭和名稱（沒有編號）。存檔裡已經玩過的地點不會被鎖回去；開發模式全部打開。原因：後面的地點假設前面教過的字已經學過。
- 地點：「回第一幕」按鍵（電腦上在左邊名牌的下面），下面是這個地點的 8 個任務（第三、四幕 9 個），一個任務一個按鍵。已完成的顯示星星，下一個顯示「新任務」，其他顯示鎖頭和「先完成上一關」。打開的地點，第一個任務都開放。

**每幕最後一格是結業考**（2026-11-24）：地點格的最後一格是「第N幕結業考」，不是地點。還沒開的時候是虛線框加鎖頭，寫「還有 N 個任務」（這一幕還沒玩過的任務數）；這一幕的任務都玩過以後，格子寫「多益題型練習・約 M 分鐘」，考過就加「・已考過 N 次」。按下去進結業考，見「幕結業考」一節。

其他規則：

- 第一次進小鎮時打開「下一關」所在的那一幕（只看已打開的幕）；之後記得你上次看的幕和地點（只記在這次開啟期間），從任務回來會回到同一個畫面。
- 「下一關」的順序：先接著上次玩的地點，那裡沒有新任務了就照遊玩順序找第一個還沒玩過的任務。
- 四幕和各幕的地點寫在 `src/content/acts.ts`：第一幕 10 個、第二幕 8 個、第三幕 12 個，第四幕 12 個（2026-11-24 四幕都做完了）。`src/data/units/` 有同樣 id 的單元檔，那一格就會自動變成可以玩；測試會檢查每個單元檔都列在某一幕裡。
- 手機直放時，地點格子和任務（關卡）按鍵平分幕的按鍵和「今日複習／下一關」下面剩下的高度，每列最高 56px、不會比內容矮：高的手機按鍵比較大，矮的手機維持原本的大小、不用多捲。高度 700px 以上時，還沒開放的地點格子和開放的一樣高（兩行）。
- 高度不到 660px 的直向畫面（舊手機，或瀏覽器工具列很高時），幕的按鍵、「回第一幕」和地點格子會矮一點，讓 10 個地點和 8 個任務仍然放得下；第三幕是 12 個地點、9 個任務，這個高度下放不放得下還沒量過。
- 每個地點的任務都播同一首 cafe 音樂（見 [audio.md](audio.md)）。

## 任務

1. **劇情**：小劇場（第一到三幕共 30 個地點各有一個場景，例如咖啡廳是店員和你在櫃檯前，搬家第一天是房東或鄰居和你在新家玄關，街道是公車站，公園是池塘邊的步道，銀行是櫃員櫃檯，修車與維修的任務會在你家廚房和修車廠之間換背景；只畫這個任務有說話的角色），說話的人會動；手機填滿上方的街景區，電腦是左邊一欄、任務卡片在右邊；新詞塊和練習時小劇場停在劇情最後的畫面，版面不變，播音檔時說那句話的人會動（規格見 [scene-stage.md](scene-stage.md)）；台詞一句一框依序出現，每句自動播放；每句旁邊有「慢速」；下方有「中文：開／關」和「下一句」（最後一句後變成「認識新詞塊」）。
2. **新詞塊**：一張卡一個詞塊或單字，有「聽發音」「慢速」、中文和文法小抄，按「下一張」。手機直放時，劇情的「下一句」、新詞塊的「下一張／開始練習」、角色扮演的「開始」和「看結果」固定在畫面最下面，拉成寬的按鍵（旁邊留「中文」或「上一張」），位置不隨內容長短移動。每張卡出現時自動用一般速度唸一次（按「上一張」回來也會唸）；聽辨卡先唸左邊再唸右邊；離開時停止播放。
3. **練習**：手機直放時，題目和說明在上面、緊接著場景，答案按鍵（選項、字塊和答案框、拼字鍵盤、錄音鍵、聽對話的框）放在畫面最下面，拇指好按；最下面是整排寬的「繼續」，一開始就在、反灰，答完才能按，回饋出現在按鍵和「繼續」之間，按鍵往上讓位；排句子用整排寬的「檢查」（旁邊是「重排」），拼字和說說看用自己的確認鍵，不另放反灰的「繼續」。iPhone 的瀏海、圓角和底部的長條都會預留空間（`viewport-fit=cover` 加 `env(safe-area-inset-*)`），按鍵不會被遮住或太靠近長條。橫放和電腦照舊由上往下排。上方有進度（例如 3 / 7）、連擊、愛心（●○）；愛心用完補滿時，連擊的位置改顯示「沒關係，再聽一次」，不多佔一行；題型見 [vocab-quiz.md](vocab-quiz.md)。打字拼字題用畫面上的字母鍵盤，不叫出系統鍵盤，所以頁面不會被擠小。一個任務的題目順序是：聽音選圖 → 聽辨挑戰 → 聽音選字 → 聽力填空 → 選回應 → 讀招牌／價目 → 看圖選句 → 句子填空 → 讀短文 → 聽對話答題 → 排句子 → 打字拼字 → 跟我說（任務沒有的題型就跳過）。2026-11-22 新增的三種畫面（第一幕就有），以及 2026-11-23 第二幕開始用的三種：
   - **聽力填空**：「聽聽看，空格裡是哪個字？」。一句台詞自動播放，英文顯示在框裡、少一個字；旁邊有「再聽一次」「慢速」；下面 3～4 個字的按鍵。答完空格填上正確的字。
   - **讀招牌／價目**：「看招牌，回答問題」。一塊深色招牌（標題和幾行字，價錢靠右）、一個英文問題（中文照設定顯示）、2～4 個答案按鍵。沒有聲音。
   - **看圖選句**：「看圖，哪一句說得對？」。一張像素圖，下面 2～4 個英文句子，一行一個按鍵。答完播正確的句子；「顯示中文」開著時，正確的那句和你選的那句下面才出現中文，其他句子不顯示。
   - **句子填空**：「選出最適合放進空格的字」。一個英文句子，中間一個有框的空格；下面 3～4 個字或短語的按鍵。選了之後馬上填進空格：對了空格變綠色；錯了，錯的字留在句子裡加刪除線，正確的填在旁邊。整句的中文只在答完後出現（不管「顯示中文」）。沒有聲音，沒有動畫。
   - **讀短文**：「讀短文，回答問題」。一張紙條放簡訊、傳單、公告、廣告、表格或 email（80 個字以內），下面是英文問題（中文照設定顯示）和答案按鍵；同一篇有兩題時標「第 1／2 題」。手機直向放不下時，紙條在框內捲動，下面還有字時顯示「▼ 還有」；橫向時短文在左、問題在右。答完把答案所在的那一行標出來。沒有聲音。
   - **聽對話答題**：「聽對話，回答問題」，上面有「再聽一次」。對話自動播放，每句接著播，不顯示文字，只有兩個說話者的名牌（正在說的標 ▶）和「第 2／5 句」；播完才出現問題和答案按鍵。答完顯示整段對話，一句一框，每句旁邊有「慢速」，點一句可以單獨重聽。
   - **第三幕的四種新題型**（2026-11-23）：**文法填空**的畫面和句子填空一樣，提示是「文法填空：選出正確的形式」，4 個選項是同一個字的不同形式。**聽獨白答題**和聽對話答題用同一個畫面，提示是「聽獨白，回答問題」，只有一個說話者的名牌。**聽對話答題加圖表**在提示下面放一張文字表格，聽的時候和答題的時候都看得到，表格不唸出來。**段落填空**：一張紙條放 email、公告或訊息，有 2～4 個編號空格，一格一格問；問到的空格有框，前面的空格填上正確答案（綠框），下面是 4 個答案按鍵，最後一格答完才顯示整篇的中文；內文太長時在框內捲動，橫向時內文和答案並排。直向 390×844 走過全部 108 個任務，答題前沒有東西超出畫面；橫向 844×390 的對話加圖表在答題前超出 27 px，還沒修。
4. **結算**：星星、答對題數、金幣、學到的新內容（每個後面有一個 ♪ 鍵，按了唸一次；不自動播放，因為可能有很多個）；「回小鎮」或「再玩一次」。

**第三幕的中文**（2026-11-24）：第三幕的劇情和角色扮演一開始不顯示中文。每句旁邊有「中」鍵，點了才出現那一句的中文（鍵盤 G 開目前最新的一句）。下面的「中文：開／關」只在這個畫面有效，全部打開後每句的「中」鍵隱藏，不改設定裡的「中文」。第一、二、四幕不變。

## 角色扮演大挑戰

每個地點的最後一關，只複習。小劇場和一般任務一樣。

1. **說明**：「換你上場」、這次沒有劇本，以及要說幾句；可以切換「跟我說：關／開」（預設關），再按「開始」。
2. **對話**：上面是對話紀錄（和劇情同一種框，可以重聽、慢速），NPC 的台詞一句一句出現並自動播放；下面是排句子題，提示是「換你說：把單字排成你要說的話」，有進度、連擊、愛心。中文要按「看中文」才出現，答完就收起這個按鍵（那句會加入對話紀錄）。答完按「繼續」，你的那句加入對話，接著播 NPC 的下一句。對話紀錄比劇情矮，會自動捲到最新的一句。打開「跟我說」時，每句排完後你的那句先加入對話，下面換成跟我說題（大聲說說看、錄音、辨識），按「我說完了」或「現在不方便說話」後才播 NPC 的下一句；進度的總數變成兩倍（例如 2 / 16）。
3. **收尾**：「你完成了整段對話！」，顯示整段對話並播放最後的 NPC 台詞；下方有「中文：開／關」和「看結果」。
4. **結算**：和一般任務一樣，但沒有「學到的新內容」。

標題列右邊的「先回小鎮」可以隨時離開，進度在每答一題時就已存檔。為了不小心點到，第一次按（點或 Esc）會變成黃色的「確定離開」，4 秒內再按一次才離開，沒有再按就變回「先回小鎮」。今日複習沒有題目、單字快練還不能開始（「回每日目標」）時不用確認。

### 總覽

- 沒開的時候只有「這一幕的任務都玩過以後才能考。還有 N 個任務。」和「回小鎮」。這一幕的任務都玩過一次就能考（不擋下一幕）。
- 開了的時候寫「多益題型練習，約 M 分鐘，分成 K 段。每段考完才算數，中途離開只會丟掉那一段。」。考過就多一行「已考過 N 次，最近一次估計 聽力 X／閱讀 Y」；有一部分題目和上次相同時，多一行「有一部分題目和上次相同，分數可能偏高。」。
- 段的清單：每段一行，寫段名、「N 題・約 10 分鐘」（題目還沒備好時寫「題目還沒備好」），狀態是「未考」、「已完成」（前面有 ✓）或「準備中」（題目還沒備好，這一段不能考）。下一段會特別標出來。
- 按鍵：「開始」（Enter；有進行中的一場時是「繼續」，全部段都考完時是「看成績」）；「重新開始」（做過一段以後才出現，第一次按變成「確定重新開始？」，再按才丟掉進行中的這一場）；「回小鎮」（Esc）。進行中的一場 7 天後過期。

### 作答

- 上面一行：段名、「第 N／M 題」，閱讀段有倒數，下面一條細進度條。
- 一次一題。作答不顯示對錯，也沒有中文；按「下一題」前可以改選答案，不能回到前一題。最後一題的按鍵是「交卷」。
- 聽力題進來時自動播一次，「♪ 再聽一次」旁邊寫剩下的次數：「不限次數」、「可以再聽 N 次」，用完是「已經播過了」（按鍵停用）。沒有慢速，也沒有中文。
- 閱讀倒數到 0：第四幕自動交卷，沒答的算錯；前三幕只顯示「時間到了，可以繼續作答」，不會自動交卷。
- 「先離開」：第一次按變成「確定離開」，4 秒內再按才離開，丟掉這一段（已完成的段保留）。Esc 也是「先離開」。
- 按鍵：1～9（或 A～D）選答案，Enter（空白鍵）是「下一題」／「交卷」。

### 成績

- 標題「第N幕結業考成績」。大字「總共答對 X／Y（Z%）」。
- 每段一格（例如「聽力一」），大字寫「答對 12／16（75%）」。
- 下面小字兩行：「估計約 X 分（low～high），只能參考」和「聽力約 A、閱讀約 B」。範圍約是 ±1 個標準誤，題數少時範圍會變寬。
- 校正一行：「已依你 N 次多益練習題分數校正」，或「還沒校正：輸入一次多益（TOEIC）練習題分數後會更準」。
- 上限一行：「第N幕結業考最高只能估到 X 分」（一幕 300、二幕 425、三幕 540、四幕 700）。
- 目標比較一行，只在上限夠高、而且有目標時才出現：「和第 W 週的目標 T 比：領先／差不多／落後」。不能比時，這一行改寫「這場考試最高估到 X，不和第 W 週的目標比」。
- 落後、衝刺路線、不是重考、還沒按過時，出現虛線框：「比目標低了一些。要把衝刺延長 4 週嗎？每天的量會變少。」，按鍵「延長 4 週」「先不用」。

- 灰字：「遊戲不能保證官方分數；請用多益（TOEIC）官方練習題確認。」
- 按鍵：「重做錯題（N）」（有答錯才出現）、「回小鎮」（Enter）。

## 跳級考

給已經有基礎的人（2026-11-25）。第一到三幕各有一份，是那一幕結業考的精簡版：

- 入口：點還沒解鎖的幕，格子上方有「已經有基礎？考過第N幕跳級考就能直接進來。」和「挑戰第N幕跳級考」。可以直接挑戰任何一幕，不用從第一幕考起；考過第三幕的就打開第四幕，第二、三幕也一起打開（`save.skipTo` 只增不減）。
- 題目：每一段每種題型，從 A、B 兩份手寫題裡隨機抽大約 A 卷題數的三分之一（至少 1 題；`pickWritten` 的 `short`）。第一幕約 12 題、第二幕 14 題、第三幕約 19 題，閱讀倒數也按題數縮短。不用新的文字或音檔。

- 「開發模式（所有關卡都能玩）：開／關」：只在開發伺服器（`npm run dev`、`npm run dev:https`）出現，打開後小鎮的所有幕和任務都開放，小鎮的總覽會提示正在用開發模式。正式版不顯示，也不理會存下來的設定。
- 「關閉」。

## 自動播放

新的英文第一次出現時自動用一般速度播放，不算用了幫助：

- 劇情的每一句、對話（角色扮演）裡 NPC 的每一句。
- 新詞卡的單字或詞塊（聽辨卡兩邊依序唸）。
- 聽的題目本身（聽音選圖／選字、聽辨挑戰、聽力填空、選回應、拼字、聽對話、應答題、看圖聽句）。
- 結業考的聽力題：進到題目時自動播一次；之後的重聽看剩下的次數（見「幕結業考」）。
- 跟我說：先播一次示範再錄音；但在對話裡剛排完、剛聽過同一句時不再播。
- 答完以後：聽音選字、聽辨挑戰、選回應、看圖選句、看圖聽句、聽力填空、排句子、拼字、應答題會播正確答案（聽力填空播整句）。
- 閱讀類（讀招牌、句子填空、段落填空、讀短文）沒有音檔，不播。
- 結算的學到的新內容不自動播，每個有 ♪ 鍵。

## 鍵盤

電腦上可以只用鍵盤玩，而且只用左手就夠（2026-11-23 改成左手配置）。全遊戲用同一套按鍵（程式在 `src/ui/keys.ts`）；設定裡有「鍵盤」一覽，只在有滑鼠的電腦上顯示。

**按鍵上的鍵帽**：在電腦上按過任何一個鍵之後，有快捷鍵的按鍵裡會出現一個深色小方塊寫著鍵名（例如「下一句 空白」「慢速 Shift `」「重排 Shift Esc」「上一張 ←」）；答案按鍵的鍵帽在最前面（1、2、3…）。用滑鼠或觸控點一下就收起來，再按鍵又出現；手機上不顯示。顯示鍵帽時按鍵左右留白縮小，讓「再聽一次」和「慢速」仍在同一行。劇情最新一句的「`」（再聽一次）鍵帽在對話框右上角、和名牌同一行。按鍵停用時鍵帽變淡；答完後答案按鍵的數字鍵帽隱藏（位置保留）。螢幕閱讀器不念鍵帽。程式：`src/ui/KeyCap.tsx`，樣式在 `src/styles.css` 的 `.kc`。

規則：按著 Ctrl、Alt 或 ⌘ 時不算；在輸入框、設定對話框裡或用輸入法選字時不算；用鍵盤（Tab）把焦點移到某個按鍵上時，Enter 和空白鍵照瀏覽器原本的方式按那個鍵；用滑鼠或手指點過、只是留著焦點的按鍵不算，Enter 和空白鍵照樣是這個畫面的下一步，也不會再按一次剛點的鍵（2026-11-25，電腦上點了「慢速」再按空白鍵會又播一次慢速）。點完一秒內由程式移過去的焦點（例如答題後的「繼續」）也算點的。按住不放只算一次（Esc 和 Backspace 拿掉字時例外）。

## 無障礙要求

- 頁面語言是繁體中文；所有英文內容都標 `lang="en"`，讓螢幕閱讀器用英文念。
- 對話框是真正的按鈕，焦點在上面時按 Enter 或空白鍵可以重聽。
- 設定是對話框：開啟時焦點移進去，Tab 不會跑到後面，按 Esc 關閉，關閉後焦點回到「設定」。
- 換畫面時焦點移到新畫面的標題；答題後焦點移到「繼續」，對錯會被讀出來。
- 允許雙指縮放；手機上的主要按鈕至少 44px 高。
- 對錯不只靠顏色表示。
- 尊重系統的「減少動態」設定。
