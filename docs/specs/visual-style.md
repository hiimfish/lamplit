# 美術與介面風格

街景、介面、像素圖示和版面縮放的規格。使用者已確認目前的畫面和操作方式，修改前要先確認。

## 方向

風格混合三位畫家的方向，**全部是原創美術，只取方向，不複製任何作品**：

| 參考方向                                             | 用在哪裡                                           |
| ---------------------------------------------------- | -------------------------------------------------- |
| 日常場景、暖色燈光、光影細緻、大部分靜止只有細微動態 | 街景主體                                           |
| 夜晚霓虹、復古未來感                                 | 咖啡廳和店家的霓虹招牌                             |
| 台灣街頭元素、有限配色、圖鑑式的物品圖               | 騎樓、機車、電線桿等街景元素；介面配色；單字像素圖 |

參考圖放在 `docs/art-image/`，只在本機參考，已被 git 忽略，**不可 commit 或發布**（是其他畫家的作品）。其中一張含任天堂角色的同人圖，那些角色不可出現在遊戲裡。

## 街景（Phaser 畫布）

- 傍晚藍調時刻的台灣街角側視圖，咖啡廳永遠在正中央。
- 咖啡廳：大窗戶透出暖光，可以看到吊燈、吧台、咖啡機和店員；招牌是粉紅霓虹咖啡杯。
- 周圍：麵攤、手搖飲、雜貨店、鐵捲門；騎樓柱子、機車、交通錐、郵筒、電線桿和電線；樓上有鐵窗、冷氣機、晾衣服、水塔。
- 天空：深藍到紫到玫瑰色的漸層、星星、細月；遠處樓房有零星亮燈的窗戶。

規則：

- **配色限制在 32 色以內**（目前 30 色，定義在 `src/game/palette.ts`，有測試檢查）。
- 形狀一律是硬邊像素，不做反鋸齒；只有光暈可以用半透明或網點。
- 大部分靜止，只有幾個週期不同的小動態：主角走到咖啡廳窗前往裡看、路人和機車經過、貓尾巴、熱氣、水窪漣漪、燈泡和霓虹偶爾閃爍。
- 系統設定「減少動態」時完全靜止。
- 同樣的畫面大小一定畫出同樣的畫面（固定種子）。
- 畫面上限 30 fps，節省手機電量。

## 介面配色

| 名稱      | 色碼      | 用途                             |
| --------- | --------- | -------------------------------- |
| ink       | `#1d1a2b` | 文字、邊框、陰影                 |
| paper     | `#f3e9d2` | 卡片底色                         |
| lamp      | `#f2a541` | 主要按鈕、選取狀態、進度條       |
| lamp-tint | `#f3ce98` | 「你」說的台詞的底色、滑過的按鈕 |
| neon      | `#ff5c8a` | 點綴：連擊、新任務標籤、愛心     |
| good      | `#3f8f5a` | 答對的邊框和標記                 |
| bad       | `#c4473a` | 答錯的邊框和標記                 |
| dim       | `#9a8f7a` | 只用在停用的按鈕                 |

對比規則：文字只用 ink 配 paper／lamp／lamp-tint，或 paper／neon 配 ink 底。neon、good、bad、dim 不拿來寫小字。

## 介面原則

- **所有能按的東西都是有框的按鈕**：米色底、2 像素墨色框、右下硬陰影，按下會往下沉。主要按鈕用 lamp 底色。
- **對話一句一個框**，「慢速」按鈕緊貼在那一句旁邊；點框本身可以重聽。
- 不能按的資訊（例如「即將開幕」）不做成按鈕；鎖住的項目用虛線框加小鎖頭，文字仍用 ink 確保可讀。
- 單字圖用像素小圖，不用 emoji（emoji 只是缺圖時的備用）。

## 版面縮放

- 畫面以整數倍放大，每個邏輯像素在螢幕上一樣大，像素不會變形。
- 邏輯畫面大小會在範圍內伸縮以填滿螢幕：橫向寬 400 到 560、高 225 到 315；直向寬 240 到 400、街景高 120 到 180。
- 直向（手機）：街景在上，介面在下。橫向（電腦）：介面卡片疊在街景上。
- 介面尺寸以邏輯像素計算（CSS 變數 `--px`），文字大小是 11 的倍數。
- 手機上的主要按鈕、選項和字塊至少 44px 高。

## 字型

- 俐方體 11 號（Cubic 11，SIL OFL 授權），原檔未修改，授權文件放在 `public/assets/fonts/`。
- 介面不要用字型沒有的 ▶ ◀ ♥ ✓ ✗；可以用 ♪ ★ ● ○ 和箭頭，三角形等圖示用 CSS 畫。
- 字型檔只有 400 KB，不裁字。OFL 規定修改後的字型不能沿用「Cubic／俐方體」的名稱，裁字也算修改。
- **KK 音標**：字型缺大部分音標符號（母音缺 ɪ ɛ ɑ ɔ ʊ ʌ ə ɚ ɝ，子音缺 ʃ ʒ ŋ，重音缺 ˏ）。另一套開源像素字型 Fusion Pixel 也補不上。目前缺的符號會由系統字型代為顯示；要正式顯示音標時，再決定自己畫這些符號，或使用授權合適的其他字型。可用 `node scripts/check-font-glyphs.mjs <字型檔>` 檢查。
